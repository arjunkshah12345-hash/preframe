# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 0.1.x | ✅ Experimental — best-effort |

## Reporting a vulnerability

PreFrame is a client-side scheduling library. Still, please report anything that could:

- Cause unexpected denial of service in consumer apps via pathological scheduling  
- Leak data through malicious `env` injection in shared hosts  
- Compromise the Vite transform into rewriting unmarked code  

**Do not** open a public issue for sensitive reports.

Email the maintainer via the GitHub profile on [arjunkshah12345-hash/preframe](https://github.com/arjunkshah12345-hash/preframe), or open a **private** security advisory on the repository.

We will acknowledge within a few days when possible. There is no bug bounty yet.
